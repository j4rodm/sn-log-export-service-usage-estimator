How to query your instance for record counts

Run these as Background Scripts (System Definition → Scripts — Background) to get last month's record counts for each table. Copy the printed value into the corresponding input field above.

syslog

// syslog record count for last calendar month
var ga = new GlideAggregate('syslog');
ga.addAggregate('COUNT');
ga.addQuery('sys_created_on', '>=', gs.beginningOfLastMonth());
ga.addQuery('sys_created_on', '<', gs.endOfLastMonth());
ga.query();
if (ga.next())
    gs.print('syslog last month: ' + ga.getAggregate('COUNT'));
